## 复现

在安装后端依赖后运行：

```bash
cd backend
python -m pytest -q --basetemp ../.test-temp-local
cd ..
python tools/verify_scenario.py
```

验证脚本会显式禁用外部模型调用，并将报告写入本地 scenario/verification.json（不提交到仓库）。
