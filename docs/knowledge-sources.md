# 知识来源与证据口径

我根据开发阶段的电商客服业务说明整理了本仓库的流程知识，覆盖比价导购、二手鉴定、售后理赔、订单咨询及图像取证。示例知识由我按业务组组织，属于应用开发资料，不是电商平台正式政策或真实订单数据。

每份示例文档保留来源与适用范围；正式规则需补充可核验的发布主体、来源位置、适用平台、版本和生效时间。价格事实还需商品规格及采集时间，个人订单结果需授权接口。

参考资料中的金额、工具规划和模型训练案例不等于本系统的实时结果。图像增强只能帮助阅读，不能替代品牌鉴定；疑似非正品也不等于平台已经批准赔付。

我将当前23项专业能力的用途和接入状态记录在 scenario/capability_catalog.json。当前运行时提供文档检索与咨询，直接图像咨询和外部业务操作有待接入。

工程开发参考与第三方库见根目录 THIRD_PARTY_NOTICES.md；原始个人资料、聊天记录和本机审计文件不属于公开知识库。
