# 知识来源与证据边界

仓库中的示例知识按七个业务组组织，覆盖商品检索、比价导购、退款、订单物流、二手鉴定流程、售后理赔和图像取证，供本地开发体验使用。

示例内容是流程说明，不是平台正式政策或真实订单数据。正式接入时，每份文档应保留发布主体、来源位置、适用平台、版本和生效时间；价格事实还需商品规格及采集时间，个人订单结果需来自授权接口。

`scenario/capability_catalog.json` 描述 23 项能力的用途和接入需求。`knowledge_only_not_registered` 表示知识说明，尚未注册成可执行业务接口。图像处理、查价、真伪判断、退款和赔付的实际执行均需相应服务及证据支持。

当前支持的咨询范围与运行状态见 [部署说明](deployment.md#当前运行状态)，代码来源和第三方组件见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。
